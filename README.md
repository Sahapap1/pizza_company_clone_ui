🍕 Pizza Company UI Clone

A frontend project that replicates the homepage UI of a popular pizza delivery website in Thailand using only HTML, CSS, and JavaScript. This project focuses on layout design, responsiveness, and user interface development.

🚀 Features
🎯 Clone of homepage UI (layout & design)
📱 Fully responsive (Desktop / Tablet / Mobile)
🎨 Clean and modern UI styling
⚡ Built with pure HTML, CSS, and JavaScript (no frameworks)
🛠️ Tech Stack
HTML5
CSS3 (Flexbox / Grid / Responsive Design)
JavaScript (Vanilla JS)
